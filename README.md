# north_korea_plate

North Korean licence plates for `plate_core`: the 1990s liveries on the
worldlicenseplates.com reference sheet.

| Spec | Format | Themes |
|---|---|---|
| `KPPlates.regional` | 평남 68-366 | `KPThemes.private` (amber), `KPThemes.government` (aluminium) |
| `KPPlates.diplomatic` | 외-07-01 | `KPThemes.diplomatic` (blue) |
| `KPPlates.military` | ㄱ·865607 | `KPThemes.military` |
| `KPPlates.vip` | ★-360 | `KPThemes.vip` (crimson frame) |

## South Korea

A region of this package, under `lib/src/south_korea/` (`SouthKoreaPlates`,
`SouthKoreaThemes`, `SouthKoreaValidator`): private, commercial, military,
diplomatic, US Forces and neon-green plates, one slot per field, with Hangul
pickers from `SouthKoreaAlphabets`.

## Not shipped

- The post-2016 liveries the article describes in words (blue state-owned,
  green diplomatic, red foreign-owned): there is no image to sample their
  colours from, and colours here are sampled, never read off adjectives.
  The specs fit them; only the themes are missing.
- A crimson star: labels paint in the theme ink, so the VIP star is navy.
- No physical size is published; the 440×140 canvas is the median measured
  aspect ratio.

## Fonts

None bundled. The goldens use Noto Sans CJK Bold, which covers Hangul and
digits in one face.
